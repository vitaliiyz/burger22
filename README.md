# Burger 22

Официальный двуязычный сайт Burger 22 во Вроцлаве: главная страница, актуальное меню, контакты и переход к онлайн-заказу.

Сайт написан на HTML, CSS и vanilla JavaScript. Сборка и установка frontend-зависимостей не нужны.

## Что есть в проекте

- Главная страница с hero-блоком, преимуществами, отзывами Google и выбором способа заказа.
- Меню на польском и английском языках с ценами, фотографиями и информацией о заказе навынос.
- Страница контактов с часами работы, телефоном, соцсетями и картой.
- Общие динамические header/footer, конфигурация ресторана и переключение языка.
- Перенаправление `/order/` на `https://order.site/burger-22`.
- Cloudflare Worker для отправки заказов в Telegram. Он сохранён в проекте, но текущий публичный интерфейс использует внешний сервис заказа.

## Структура

```text

├── styles.css                 # Стили главной
├── home.js                    # Переводы, отзывы, modal заказа
├── reviews-data.js            # Рейтинг и выбранные отзывы Google
├── contact.html               # Контакты
├── contact-styles.css
├── contact.js
├── common/
│   ├── common.js              # Общая конфигурация, i18n, header/footer
│   ├── common.css
│   └── images/
├── menu/
│   ├── index.html
│   ├── styles.css
│   ├── app.js
│   ├── translations.js
│   └── images/
├── order/index.html           # Резервный HTML-редирект
```

Header и footer не хранятся в отдельных HTML-файлах: их разметку создаёт `common/common.js`.

## Локальный запуск

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Открыть: [http://localhost:8000/](http://localhost:8000/)

Локальный HTTP-сервер предпочтительнее прямого открытия файлов, поскольку он корректнее повторяет работу относительных путей и навигации.

## Где менять данные

| Что меняется | Файл |
| --- | --- |
| Телефон, email, адрес, часы, соцсети | `common/common.js` |
| Тексты главной и URL прямого заказа | `home.js` |
| Разметка главной | `index.html` |
| Рейтинг и фрагменты отзывов Google | `reviews-data.js` |
| Позиции и цены меню | `menu/index.html` |
| Польские и английские тексты меню | `menu/translations.js` |
| Контактные переводы | `contact.js` |
| Редирект `/order/` | `_redirects`, `order/index.html` |

При изменении меню синхронно обновляйте польскую и английскую версии. Цена обычно хранится в `menu/index.html`, а переводимые названия, описания и часть ценовых подписей — в `menu/translations.js`.

## Переводы

Текущий язык хранится в `localStorage` под ключом `burgerLang`; по умолчанию используется польский.

Общие переводы находятся в `common/common.js`, а переводы страниц — в:

- `home.js`;
- `contact.js`;
- `menu/translations.js`.

HTML-элементы связываются с переводами через `data-i18n`. После смены языка общее ядро отправляет событие `languageChanged`, и скрипт страницы обновляет свои тексты.

## Отзывы Google

Главная страница читает данные из `reviews-data.js`. При обновлении обязательно проверить публичный профиль Google и изменить вместе:

- `rating`;
- `reviewCount`;
- `reviewsUrl`;
- `lastVerified`;
- выбранные отзывы и оба языка их текста.

Отзывы создаются безопасными DOM-методами через `textContent`.

## Онлайн-заказ

Основной URL заказа: `https://order.site/burger-22`.

Он используется на главной, в меню и в двух вариантах редиректа `/order/`. При смене адреса проверьте как минимум `home.js`, `menu/index.html`, `order/index.html` и `_redirects`.

Cloudflare Worker можно запускать отдельно:

```bash
wrangler dev
```

Для локального запуска Worker нужен некоммитящийся файл `.dev.vars`:

```text
TELEGRAM_BOT_TOKEN=...
```

Секреты нельзя добавлять в Git.

## Cache busting

После изменения видимых CSS/JS, переводов или данных обновляйте query-параметр версии в соответствующем HTML:

```html
<link rel="stylesheet" href="styles.css?v=YYYYMMDD-N">
<script src="home.js?v=YYYYMMDD-N"></script>
```

Для `common/common.css` и `common/common.js` версия должна быть согласована на главной, в меню и на странице контактов. Это особенно важно для Safari и мобильных браузеров с агрессивным кешем.

## Проверка перед коммитом

- Открыть главную, меню, контакты и `/order/`.
- Переключить PL/EN на каждой странице и проверить сохранение языка.
- Проверить мобильное меню, footer, телефон, копирование и внешние ссылки.
- Проверить отзывы и modal заказа на главной.
- Проверить меню, изображения, цены и sticky-навигацию.
- Проверить узкий, средний и широкий мобильный viewport, затем desktop.
- Убедиться, что изменённые ассеты получили новую версию.
- Выполнить `git diff --check`.

Автоматических тестов в репозитории сейчас нет.

## Deployment

Workflow `.github/workflows/deploy-worker.yml` разворачивает только Cloudflare Worker при изменении его файлов на настроенных ветках. Механизм публикации статической части сайта в этом репозитории не описан; его нужно подтверждать отдельно в настройках хостинга.

Домен сайта задаётся файлом `CNAME`: `burger22.pl`.
